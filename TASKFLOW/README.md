# RD Infro Technology Web Development Internship

## Project Name: Full-Stack Task Manager App

### Task 1: Requirement Gathering & Planning
This full-stack application is designed to help users organize, track, and manage their daily activities safely and dynamically.

**Planned Application Core Features:**
1. User Authentication: Private Signup and Login forms to protect data.
2. User Dashboard: A secure main workspace page seen only after logging in.
3. Task Operations: Clear functions to Add new tasks, view existing tasks, and Delete completed tasks.

**Technology Tools to Use:**
* Frontend: HTML, Tailwind CSS, JavaScript / React.js
* Backend & Storage: Node.js, Express, MongoDB
* Development Workspace: VS Code, GitHub
